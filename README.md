# Agent-Toolkit

[中文](README.zh-CN.md)

A collection of agent capability extensions: reusable Agent Skills, MCP Servers, and AI development workflows.

## Structure

```
General/                  
├── Skill-Hub/
│   ├── webapp-testing/
│   ├── code-simplifier/
│   ├── frontend-design/
│   ├── mcp-builder/
│   ├── skill-creator/
│   ├── doc-coauthoring/
│   ├── firecrawl-cli/
│   ├── firecrawl-parse/
│   └── smart-web-scraper/
└── MCP-Hub/
    ├── figma-mcp/
    ├── context7/
    └── playwright-mcp/
Personal/                 
├── Skill-Hub/            
│   ├── handoff-skill/        
│   ├── weekly-report-skill/
│   ├── git-commit-skill/
│   └── first-principles-build-skill/
└── MCP-Hub/              
    ├── sandbox-docker-mcp/
    └── vision-bridge-mcp/
Workflows/
├── spec-driven/
├── ralph-loop/
└── multi-agent/
```

- **`General/`** — a curated collection of excellent open-source agent skills and MCP servers.
- **`Personal/`** — personal, self-built skills and MCP servers for my own workflows.
- **`Workflows/`** — methodology and templates for AI development workflows (spec-driven, autonomous loop, multi-agent orchestration).
