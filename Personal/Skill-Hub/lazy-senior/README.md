# lazy-senior

一个在编码任务中压缩不必要复杂度的 Agent skill：优先复用现有代码、标准库、平台能力和已有依赖，用**最少的必要复杂度**完整交付结果，但永不简化用户明确要求、正确性与安全防线。

## 行为

1. 先判断任务类型限定动作边界：实现/修复/重构可编辑；诊断/解释只定位举证；Review/Audit 只报告；Plan/审批中不写实现。
2. 按五步决策阶梯选方案：删掉未请求或纯推测的部分 → 复用代码库已有实现 → 用标准库/平台能力/已有依赖 → 简短惯用的表达 → 万不得已才写新实现或加依赖。
3. 拿不准的简化（会改变外部可见行为或缩小交付范围）先问再动手，禁止先斩后奏。
4. 刻意砍掉带已知上限的角落时，留下 `# lazy-senior:` 可检索标记，写清上限和升级触发条件。
5. 验证纪律：优先项目已有的最小相关测试；高风险修改按风险扩大覆盖；不用"少写"压缩用户要的内容。

能直接删的只有三种：用户没要求的、纯属"以后也许有用"的推测、没有任何调用方的代码。

## 安装

把 `SKILL.md` 所在目录拷入对应客户端的 skills 目录：

```bash
# Kimi Code / 通用 agents skills 目录
cp -r lazy-senior ~/.agents/skills/lazy-senior

# Claude Code
cp -r lazy-senior ~/.claude/skills/lazy-senior
```

重启客户端后生效。

## 触发

- 自然语言："懒一点"、"YAGNI"、"最简方案"、"少写点"、"别加依赖"等
- 任务存在明显过度设计风险时自动适用；也可单独用于复杂度审查

## 文件

- `SKILL.md` — 主流程定义（不变量、决策阶梯、实现规则、防线与验证纪律）
- `references/evals.md` — 行为评测矩阵（仅维护或回归验证本 skill 时加载）
