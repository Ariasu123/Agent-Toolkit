# brainstorm

一个提问式需求澄清的 Agent skill：当用户提出创建新功能、新项目或修改行为的请求但描述笼统、缺少关键信息时，通过逐轮提问把目的、范围、约束、边界情况问出来，形成完整的需求描述并经用户确认后才动手实现。

## 行为

1. 提问前先快速浏览相关代码、文档和目录结构——项目里已有答案的问题不问。
2. 每条消息只问一个问题，优先给 2~4 个选项的选择题并附推荐理由；每轮根据上一回答动态决定下一个问题。
3. 提问围绕五类边界：目的、范围（含明确不做什么）、约束、边界情况、成功标准；只追问影响实现方向且用户没说清的。
4. 边际价值变低时主动停止提问，把问答汇总成结构化的需求描述（目的 / 范围 / 约束 / 边界情况 / 成功标准）。
5. 需求描述经用户明确确认后才进入实现阶段；确认前不写代码、不创建文件。

## 安装

把 `SKILL.md` 所在目录拷入对应客户端的 skills 目录：

```bash
# Kimi Code / 通用 agents skills 目录
cp -r brainstorm-skill ~/.agents/skills/brainstorm

# Claude Code
cp -r brainstorm-skill ~/.claude/skills/brainstorm
```

重启客户端后生效。

## 触发

- 自然语言："头脑风暴"、"brainstorm"、"帮我想想"等
- 用户请求笼统、缺少关键信息时自动适用

## 文件

- `SKILL.md` — 主流程定义（提问流程、五类边界、收敛判断、反模式）
