# MCP-Hub

优秀开源 MCP（Model Context Protocol）server 精选收录，**包含完整源码**，可直接从本仓库获取。

## 收录清单

| Server | 功能 | 上游 | 许可证 |
|---|---|---|---|
| **figma-mcp** | Figma 设计稿上下文读取、design-to-code（社区最流行的开源实现，npm 包 `figma-developer-mcp`；Figma 官方 MCP 不开源） | [GLips/Figma-Context-MCP](https://github.com/GLips/Figma-Context-MCP) | MIT |
| **context7** | 向 AI 客户端注入最新版库/框架文档，消除"幻觉 API" | [upstash/context7](https://github.com/upstash/context7) | MIT |
| **playwright-mcp** | 浏览器自动化、UI 测试，基于可访问性快照驱动浏览器 | [microsoft/playwright-mcp](https://github.com/microsoft/playwright-mcp) | Apache-2.0 |

## 说明

- 各目录为上游仓库某一版本的完整快照，未做功能修改；跟进更新请回溯上游。
- 再分发时请遵守对应项目的许可证要求。
