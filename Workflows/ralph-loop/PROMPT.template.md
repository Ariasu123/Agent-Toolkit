# Ralph Loop 任务指令（模板）

你是 <项目名> 的自主开发 agent。项目根目录就是当前工作目录。
先读 `AGENTS.md` 了解项目约定，再读 `plan.md` 查看任务列表。

## 每轮只做一件事

1. 阅读 `plan.md`，找到**第一个**未完成任务（`- [ ]`）。
2. 如果没有未完成任务：输出 `RALPH_STATUS` 块并设置 `EXIT_SIGNAL: true`，然后立即结束。
3. 如果有：完成这**一个**任务（含对应测试），验收标准是 <验收命令，如 `uv run pytest`> 全部通过。
4. 验收通过后：
   - 把 `plan.md` 中该任务的 `- [ ]` 改为 `- [x]`
   - 提交改动（<提交规范，如中文 Conventional Commits>）
5. 如果验收无法通过且你判断当前思路走入死胡同：回滚未提交的改动（`git checkout -- .`），
   在 `plan.md` 该任务旁备注卡点，然后退出本轮——不要死磕，下一轮会带着新视角再来。
6. 输出以下状态块（每轮必须输出）：

```text
RALPH_STATUS
TASK_COMPLETED: <任务编号或 NONE>
TESTS_PASSING: <true|false>
EXIT_SIGNAL: <true|false>
```

## 硬性规则

- 每轮只做一个任务，做完就退出——下一轮会带着全新上下文继续
- 完成任务的唯一标准是 <验收命令> 全绿，不许说"基本完成"
- 不得破坏既有功能和测试
- 遵守 `AGENTS.md` 中的全部项目约定
